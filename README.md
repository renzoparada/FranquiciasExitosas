# Franquicias Exitosas · Portal ESCALA

Plataforma donde el consultor gestiona proyectos de franquiciamiento con el **Método ESCALA®** ("Estructura · Desarrolla · Expande") y cada cliente ve en línea el avance de su proyecto.

- Propuesta de modelo de datos y mapa de pantallas: [`docs/01-modelo-de-datos-y-pantallas.md`](docs/01-modelo-de-datos-y-pantallas.md) (pendiente de aprobación).
- Stack: Next.js (App Router) + TypeScript + Tailwind + shadcn/ui · Supabase (Postgres, Auth, Storage, Realtime) · Vercel.
